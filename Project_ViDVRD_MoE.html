01 · Problem

Who does what to whom

The question

Can a model describe what happens in a video as simple sentences, such as person – ride – bicycle, and stay reliable across the many possible combinations?

SubjectPredicateObject

personstand next tocar

Every subject can meet every predicate and every object, so the possible sentences multiply quickly.

Background

Video relationship detection describes interactions in a video as language triplets of subject, predicate and object, such as person–ride–bicycle. It sits where vision meets language, and single monolithic classifiers often struggle to generalize and stay stable across the many possible combinations.

Video relationship detection must solve object, subject and action recognition at once, while relationships change over time. Since the first approach and dataset in 2017, methods have used segment-wise prediction with greedy association, spatio-temporal graphs, sliding windows and, more recently, transformers. VidVRD-II added preferential predictors that refine each part of the triplet using the other two; it serves as the expert here.

These are single, monolithic networks. Their training cost grows roughly quadratically with size, and they tend to be brittle when the data shifts. A sparsely gated mixture of experts offers a way around this: many small networks, with a gate that activates only a few of them for each input, adding capacity without adding computation.

02 · Proposed solution · Method

A team of small experts

MoE-VRD splits the problem across a mixture of lightweight experts, each specialized in relationship learning and object tagging. Sparse gating means only a few experts run for each input, adding capacity without adding computation.

How it works

  1. 1Track objectsFaster R-CNN detections are linked over time into tracklets with Seq-NMS.
  2. 2Describe themDeep features of what subject and object look like, plus where they are relative to each other.
  3. 3GateA gating network scores all 10 experts and keeps the top 2 for this input.
  4. 4PredictEach active expert predicts subject, predicate and object, using two parts to refine the third.

A gating network scores all experts for each input and keeps only the top K. Learnable noise makes the selection trainable, and an importance loss keeps the load balanced so a few favoured experts don't take over.

How many experts to use

With 10 experts in total, using the top 2 for each input works best on both benchmarks; using more lowers accuracy.
